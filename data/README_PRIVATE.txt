# Dataset sharing notice

The source Roboflow export marks the original dataset as **Private**.

For now this repository documents metadata and expected folder structure without releasing the photographs or annotations. Please verify image ownership, consent (where needed), team approval and applicable redistribution permissions before any public release.

Expected local data tree:
\`\`\`
data/dataset/
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
\`\`\`

\`data/dataset/\` is ignored by Git. Contact the maintainer regarding authorized access.
