# Contribution and authorship

Smart Bin was built during an ENPO engineering hackathon as a **team project**.

This repository is maintained and documented by Ayoub ANANI. It preserves the supplied Arduino sketch and the historical computer-vision experiment, plus later documentation, dataset audit and reproducibility scripts.

**Do not infer individual ownership** of specific tasks solely from repository authorship: team-role details were not supplied with the archive. If teammates' names, approvals, videos or more original source become available, they can be added with proper attribution.

Contributions and correction reports are welcome. Do not upload private images, trained models, API keys or third-party dataset assets without authorization.
